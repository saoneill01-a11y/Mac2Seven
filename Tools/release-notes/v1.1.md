Mac2Seven now keeps itself up to date.

## Download
Download **Mac2Seven.zip** below, unzip it, and drag **Mac2Seven** into your Applications folder (replace the old copy if you have 1.0). Requires **macOS 14 Sonoma or later**. Signed with a Developer ID and notarized by Apple.

## New in 1.1
- **Automatic updates.** Mac2Seven checks for new versions once a day and asks before installing. You can also choose **Check for Updates…** from the menu bar icon's right-click menu, or turn automatic checks off in **Settings → General**.

If you're on 1.0, install this version by hand once. After that, updates arrive on their own.
