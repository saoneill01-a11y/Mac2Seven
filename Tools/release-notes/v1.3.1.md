Mac2Seven 1.3.1 lets you rearrange the taskbar, resize the Start menu, and set text sizes, plus many fixes.

## Download
If you have 1.1 or later, Mac2Seven will offer this update on its own (or choose **Check for Updates…** from the menu bar icon's right-click menu). Otherwise, download **Mac2Seven.dmg** below, open it, and drag **Mac2Seven** into your Applications folder. Requires **macOS 14 Sonoma or later**. Signed with a Developer ID and notarized by Apple.

## New in 1.3.1
- **Rearrange the taskbar.** Drag any button, pinned or not, to a new place; a blue line shows where it will land, and the order is remembered. With a button per window, you can also drag a window between the other windows of the same app.
- **Open apps stand out.** Apps with a window open sit on a tile with a border, and the app you're using on a stronger one. Apps that are running with no windows keep just their small dot.
- **Resize the Start menu.** Drag the grip in its corner; double-click the grip to go back to the normal size. Your size is remembered.
- **Text size.** Separate sliders for the Start menu and the taskbar in **Settings → Appearance**. The Start menu size also makes All Programs' icons and folders bigger.
- **Apple folder.** **Settings → Organize** can move Apple's own apps (Safari, Mail, Calendar…) into an Apple folder, and new Apple apps go straight there.
- **The Dock comes back when Mac2Seven quits.** If you used **Hide the Dock**, the Dock is shown again whenever Mac2Seven isn't running and hidden again when it starts.
- **A bigger Start button.**

## Fixes
- Window previews and dragging on the taskbar could stop working after apps opened or closed windows.
- Rearranging didn't work on a display to the left of the main one.
- Control-clicking a taskbar button could also click it.
- The Start menu could run off the top of the screen or behind the taskbar, and could end up smaller than intended.
- After you cancel Snip, the app you were using gets the keyboard back.
- An app that stops responding no longer slows down the taskbar.
- **Show the Dock Again** now restores your own Dock auto-hide setting.
- Fixed a case where the Start menu could freeze after changing the text size.
