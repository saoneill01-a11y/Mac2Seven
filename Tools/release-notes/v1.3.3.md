Mac2Seven 1.3.3 adds pinning from both right-click menus, a menu for Snip's thumbnail, and taskbar menus that open above the bar.

## Download
If you have 1.1 or later, Mac2Seven will offer this update on its own (or choose **Check for Updates…** from the menu bar icon's right-click menu). Otherwise, download **Mac2Seven.dmg** below, open it, and drag **Mac2Seven** into your Applications folder. Requires **macOS 14 Sonoma or later**. Signed with a Developer ID and notarized by Apple.

## New
- **Pin to Taskbar from the Start menu.** Right-click an app in the Start menu or All Programs and choose **Pin to Taskbar** (or **Unpin from Taskbar**).
- **Pin to Start Menu from the taskbar.** Right-click a taskbar button and choose **Pin to Start Menu** (or **Unpin from Start Menu**).
- **Snip thumbnail menu.** Right-click the thumbnail that appears after a screenshot to open it in Preview, copy it, save it to Photos, the Desktop or Documents, Save As…, show it in Finder or move it to the Trash. The thumbnail stays up while its menu is open or the pointer is on it. Clicking a screenshot that wasn't saved opens it in Preview.

## Changes
- **Taskbar menus open above the bar**, like Windows, so they no longer cover the taskbar.
